# Getfy Gateway | Página de vendas

Landing page (Vite + React + Tailwind) para o **Getfy Gateway**, plataforma completa de gateway, checkout e infoprodutos.

## Configuração

Edite [`src/config/landing.ts`](src/config/landing.ts) para alterar:

- Link de checkout (`checkoutUrl`)
- Preço e textos da oferta
- Meta Pixel ID
- Paths dos logos (quando disponíveis em `src/assets`)

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
